# UFC Personal Portfolio

A responsive React 19 + Vite portfolio for **Udegbunem Favour Chiemerie (UFC)**, using the existing dark visual direction and lime accent.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally (Git Bash on Windows)
```bash
cd path/to/ufc-portfolio
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Add your personal images
- **Profile photo:** place your image at `public/images/favour.jpg`. The About section shows a UFC initials fallback if the photo is missing.
- **JozoStore landing-page screenshot:** place it at `public/images/jozostore-hero.jpg`. The JozoStore visual remains styled if you have not added the screenshot yet.
- **Social sharing image:** `public/og-image.jpg` is a 1200 × 630 starter image. Replace it with your own polished image if desired.

Use images you own or have permission to publish. Keep filenames consistent with the paths above.

## Personalize before publishing
1. Deploy once to Vercel if you do not have a domain yet. Copy the real public URL (for example, your actual `*.vercel.app` URL).
2. In `index.html`, replace **every** `https://YOUR-DOMAIN.com` with that exact production URL, including canonical, Open Graph, Twitter, and JSON-LD values.
3. In `public/robots.txt` and `public/sitemap.xml`, replace `https://YOUR-DOMAIN.com` with the same production URL. Keep the sitemap URL ending in `/sitemap.xml`.
4. Replace `hello@YOUR-DOMAIN.com` in `src/App.jsx` with an email address you want to publish.
5. Replace `YOUR-GITHUB` and `YOUR-LINKEDIN` in `src/App.jsx` with your real profile usernames/URLs. Remove a social link if you do not want to share it.
6. Verify project descriptions and add live repository/demo links when available. Current project cards are informational and their links lead to the contact section rather than claiming an unverified live demo.
7. Commit and push your changes to GitHub. Vercel normally redeploys automatically when the connected branch receives a new commit.

**Yes, you can deploy first and update metadata afterward.** Once the real URL is known, update all URL placeholders, then commit and push. The redeployed site will publish the corrected metadata.

## SEO included
- Page title and descriptive meta description with your full name
- Canonical URL placeholder
- Open Graph and Twitter/X metadata
- Person JSON-LD structured data
- `robots.txt` and `sitemap.xml`
- Semantic sections, heading hierarchy, and descriptive image alt text
- Mobile navigation, skip link, and reduced-motion support

SEO does not guarantee a first-place ranking. After deployment, verify the domain in Google Search Console and submit `/sitemap.xml`. Use your full name consistently on the site and in professional profiles; indexing and rankings take time.

## Technology logos
The skill icons use Devicon's public CDN and need an internet connection. If an individual icon fails to load, its text abbreviation appears instead. The skills note intentionally avoids claiming expert-level proficiency in every listed technology.

## Deployment on Vercel
1. Push the project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the default Vite settings: build command `npm run build`, output directory `dist`, install command `npm install`.
4. Deploy. Test the generated URL on desktop and mobile.
5. Update metadata placeholders as described above, then push the changes to trigger a fresh deployment.

Do not commit `node_modules` or the production `dist` folder. Both are generated by npm/Vite.
